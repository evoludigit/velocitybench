## Reads — unchanged relative to peers (except the deepest nested read)

Raw FraiseQL reads rose ~+44–53% vs July, but so did every engine — it's a faster host + lean schema, not a relative gain. Against the stable PostGraphile yardstick the ratio is flat:

| Scenario | fraiseql-tv / PostGraphile (now) | (Jul-07) | shift |
|---|--:|--:|--:|
| Q1 (flat list) | 2.85× | 3.12× | −9% |
| Q2b (posts+author) | 3.11× | 3.21× | −3% |
| T1 (blog page) | 2.35× | 2.44× | −3% |

FraiseQL remains the read leader (~2.4–4× PostGraphile), no regression. **Q3 genuinely improved** (+46% relative) — the lean `tv_comment` drops the embedded post body + nested author, making the deepest nested read materially cheaper.

## Writes — the real result: a genuine, host-independent gain (but NOT "fastest write")

The multi-hop column-aware refresh cut the `updateUser(bio)` cascade fan-out from ~110 rows to ~11. Effect on the integrated write:

| | M1 (updateUser bio) | MC1 (consistency cycle) |
|---|--:|--:|
| fraiseql-tv now | **1,117 RPS** (p99 190 ms) | **1,111 cyc/s** |
| fraiseql-tv Jul-07 | 89 | 89 |
| raw improvement | **+1,161%** (~12×) | +1,144% |
| ratio vs PostGraphile: now / Jul | **0.32× / 0.04×** (+647%) | **0.72× / 0.09×** (+666%) |

The relative-to-PostGraphile jump (~6.5×) proves this is a real fan-out win, not host inflation.

**Honest scope — do not overclaim:**
- FraiseQL's integrated write (M1) is **still the slowest measured engine** on raw M1: actix 5,210 · mercurius 4,422 · postgraphile 3,503 · apollo 2,769 · hasura 1,964 · strawberry 1,316 · **fraiseql ~1,117**. The story is "**closed a ~30× gap to low-single-digit×**," not "fastest write."
- Write **tail latency is high** (p99 190 ms vs 20–30 ms for peers) — the cost of recomputing ~11 cascade rows per write.
- A `username` edit still fans out to ~61 rows (~5× the bio cost); M1 measures the cheap bio path.
- **M1d (10,155 RPS) is the isolated `jsonb_delta` patch** on dedicated `tvd_*` tables — it skips the base-table write AND the view recompute. It is not the integrated write and must never be headlined as "fastest write."
- **MC1** is the strongest honest angle: FraiseQL reaches consistent state at **0.72× PostGraphile's cycle rate with half the HTTP round-trips and zero stale reads** (1 request returns the mutation + cascade vs 2 serial requests).
